# 치지직 구독채널 그라데이션

치지직(chzzk.naver.com)에서 내가 구독 중인 채널 이름에 그라데이션을 표시해주는 Chrome 확장 프로그램입니다.

## 미리보기

팔로잉 목록, 라이브 카드 등 채널 이름이 표시되는 모든 곳에서 구독 채널을 한눈에 구분할 수 있습니다.

![사이드바](assets/screenshot-sidebar.png) ![팔로잉 채널 라이브](assets/screenshot-live.png)

## 설치 방법

1. 이 저장소를 클론하거나 ZIP으로 다운로드합니다.
2. Chrome에서 `chrome://extensions` 접속
3. 우측 상단 **개발자 모드** 활성화
4. **압축해제된 확장 프로그램을 로드합니다** 클릭
5. 다운로드한 폴더 선택

## 동작 방식

- 확장 프로그램 설치 또는 브라우저 시작 시 Naver 구독 API를 자동으로 호출합니다.
- 구독 채널 목록을 로컬에 저장한 뒤, `chzzk.naver.com` 내 채널 이름에 그라데이션을 적용합니다.
- **별도 페이지 방문 불필요** — Naver 로그인 상태라면 자동으로 처리됩니다.

## 권한

| 권한 | 용도 |
|------|------|
| `storage` | 구독 채널 목록 로컬 저장 |
| `api.chzzk.naver.com` | 구독 채널 목록 조회 |
