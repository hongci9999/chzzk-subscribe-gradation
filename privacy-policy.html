개인정보처리방침

치지직 구독채널 그라데이션 (이하 "확장 프로그램")은 사용자의 개인정보를 다음과 같이 처리합니다.

수집하는 데이터

확장 프로그램은 Naver 구독 API(api.chzzk.naver.com)를 통해 사용자가 구독 중인 채널 이름 목록을 조회합니다. 이 데이터는 사용자 기기의 로컬 스토리지(chrome.storage.local)에만 저장됩니다.

데이터 사용 목적

수집된 채널 이름은 오직 치지직(chzzk.naver.com) 사이트에서 구독 채널 이름을 시각적으로 강조 표시하는 용도로만 사용됩니다.

데이터 전송 및 공유

수집된 데이터는 외부 서버로 전송되거나 제3자와 공유되지 않습니다. 모든 데이터는 사용자의 기기 내에서만 처리됩니다.

데이터 보관

데이터는 확장 프로그램이 삭제될 때 함께 삭제됩니다. 사용자는 언제든지 Chrome 확장 프로그램 설정에서 저장된 데이터를 직접 삭제할 수 있습니다.

문의

개인정보 처리에 관한 문의는 GitHub Issues를 통해 연락하시기 바랍니다.
